# Jordan AI Platform — Free Mode

هذه النسخة مهيأة للعمل بدون Replit AI Integrations وبدون OpenAI API Key.

## ماذا تم تحسينه؟
- تحسين البحث العربي: تطبيع الحروف وإزالة التشكيل والكلمات الشائعة.
- مطابقة أذكى للأسئلة مع السجلات بدل الاعتماد على `includes` البسيط.
- إجابات من قاعدة المعرفة مرتبطة بالمصادر، مع رفض التخمين عند عدم وجود سجل مناسب.
- إضافة سجلات رسمية جديدة: الأحوال المدنية والجوازات، وزارة الصحة، ووزارة التعليم العالي.
- لا يوجد اعتماد إجباري على Replit Core أو خدمة AI مدفوعة.

## ملاحظة مهمة
هذا الوضع هو **Retrieval-first**: يعمل من المعرفة المخزنة في قاعدة البيانات. لا يدّعي أنه نموذج توليدي كامل ولا يقوم ببحث مباشر في الويب.

لاحقًا يمكن إضافة مزود نموذج اختياري عبر API بدون تغيير واجهة الموقع، لكن المشروع لا يحتاج ذلك كي يعمل.

## التشغيل على Replit
1. ارفع هذا المشروع إلى Replit.
2. شغّل المشروع بالطريقة المعتادة.
3. لا تختَر `Upgrade to Core` من أجل تشغيل وضع المعرفة المجاني.
